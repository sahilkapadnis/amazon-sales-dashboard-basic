# Amazon Sales Dashboard (Beginner Project)

## 📊 Overview

The goal was to understand how to build dashboards, use filters, and visualize sales distribution across categories, cities, and delivery partners.

---

## 🔧 Tools Used
- Power BI
- Basic Data Visualization

---

## 📈 Dashboard Features

- Total Sales (KPI)
- Top Product Categories
- Sales Distribution by City
- Delivery Partner Analysis
- Order Status Breakdown

## 🧠 Key Learnings

- Creating KPI cards and basic visuals in Power BI  
- Using slicers for filtering data  
- Designing dashboard layouts  
- Understanding categorical data distribution
